Getting started
1
Download the SDK
Click the button above to download the SDK zip. Unzip it anywhere on your machine — this becomes your local design system workspace.
2
Create a project
Inside the SDK, open the projects/ folder. Duplicate the sample project and rename it to your product. Each project gets its own folder with a CLAUDE.md that tells your AI agent how to work with this DS.
3
Explore the Pattern Library
Head to the Pattern Library tab and browse the full set of page layouts. Find the patterns your product needs — dashboards, settings, onboarding flows, data tables, and more.
4
Configure and export patterns
Open each pattern, use the Configure panel to toggle zones and set your AI rules, then download it. Each pattern exports as a ready-to-use HTML file with your brand theme and navigation model applied.
5
Start building
Drop your exported patterns into your project folder. Point your AI coding tool at the project and start prompting — it has everything it needs to build on-brand, on-standard screens.
