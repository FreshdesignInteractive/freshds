Prompt Input

The signature input for AI interactions. Communicates to users that they are talking to an intelligent system, not filling out a form. Supports optional file attachment and voice input actions.

Prompt input states
Default placeholder="..." · Standard prompt input with sparkle icon and send button.
Focused focused · Renders with visible focus ring to indicate active state.
With attach and voice show-attach show-voice · Adds file attachment and microphone buttons for multimodal input.
Disabled disabled · Disables input and all action buttons. Use when AI is processing.

General fresh-prompt-input
  • •Use prompt input as the primary entry point for all AI interactions. Never replace it with a standard text field or textarea when the AI engine is active.
  • •Set disabled while the AI is generating a response. Re-enable immediately when streaming completes or an error is shown.
  • •Use show-attach only in contexts where file or image upload is actually supported by the backend. Never surface the button speculatively.
  • •Set placeholder text to match the data or task context: "Ask about Q3 revenue..." is better than "Ask anything..."
  • •Listen for fresh-submit to send the value to the AI. Clear and re-focus the field after each successful submission so the user can continue the conversation.
Attributes
AttributeValuesDefaultDescription
placeholderstringAsk anything...Contextual hint text shown inside the input.
show-attachboolean-Shows the file attachment button. Replaces the sparkle icon on the left.
show-voiceboolean-Shows the voice/microphone input button before the send button.
focusedboolean-Renders the input with the focus ring visible. Useful for showcasing active state in demos.
disabledboolean-Disables the text input and all action buttons. Use while AI is processing.
Events
EventDetailDescription
fresh-submit{ value: string }Fired when the user clicks Send or presses Enter. Field clears automatically after dispatch.
fresh-attach{}Fired when the attach button is clicked. Open a file picker in the handler.
fresh-voice{}Fired when the voice button is clicked. Start speech recognition in the handler.

JSHandling submission
const input = document.querySelector('fresh-prompt-input');

input.addEventListener('fresh-submit', e => {
  input.setAttribute('disabled', '');
  sendToAI(e.detail.value).finally(() => {
    input.removeAttribute('disabled');
  });
});

Accessibility

Prompt input satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
Keyboard submitEnter submits the prompt. Shift+Enter inserts a newline when multi-line support is needed.
Button labelsSend, Attach file, and Voice input buttons all have descriptive aria-label attributes.
Disabled stateWhen disabled, all controls are non-interactive. Notify screen readers that the AI is processing via a live region outside this component.
