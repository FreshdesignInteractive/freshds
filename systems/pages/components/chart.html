Chart

Chart container using Chart.js. Provides the FreshDS card header, border, and a 20px-guttered chart area. The component owns a built-in canvas; initialize Chart.js by passing element.chartCanvas directly to new Chart(). Do not place a <canvas> inside the element. Use the actions slot for header controls.

Chart states
Area chart title + description · Card header is shown when either title or description is provided. Initialize Chart.js by reading element.chartCanvas and passing it to new Chart().
Bar chart default slot · Use --dv-1 through --dv-8 for series colors. Pass an array to backgroundColor for per-bar coloring across series.
Multi-series --dv-1 through --dv-8 · Use dataviz tokens in series order starting at --dv-1. Do not use brand scale tokens for chart series.
Loading + empty loading · empty · Boolean attributes for loading shimmer and empty state. Use loading when data is fetching, empty when a query returns no results.
Header actions slot slot="actions" · Place buttons or controls in the actions slot. They render top-right in the card header alongside the title and description.

General fresh-chart
  • •This component uses Chart.js v4. Load cdn.jsdelivr.net/npm/chart.js@4/dist/chart.umd.min.js before fresh-chart.js on every page that renders charts.
  • •Initialize Chart.js by calling element.chartCanvas on the <fresh-chart> element and passing the result to new Chart(). Do not place a <canvas> inside the element — the canvas is built into the shadow DOM.
  • •Always use responsive: true, maintainAspectRatio: false in Chart.js options. The canvas is already sized to fill the 20px-guttered chart area; no additional layout config is needed.
  • •Read dataviz tokens at render time: getComputedStyle(element).getPropertyValue('--dv-1').trim(). On dark mode change, destroy the chart and re-initialize by observing the data-mode attribute on document.documentElement (pattern pages) or #spec-viewport (this component doc page).
  • •Always use --dv-1 through --dv-8 tokens for chart series colors. Never use brand scale tokens (--primary-*, --secondary-*) inside charts. Assign in order starting at --dv-1; do not skip.
  • •Show the loading attribute immediately when data is fetching. Remove it and call element.chartCanvas only once data is ready. Use empty when a query returns no results.
  • •Load tokens/dataviz.css on any page that uses fresh-chart. The --dv-* tokens are defined there and are not included in theme.css.

Slots
SlotDescription
actionsButtons or controls rendered top-right in the card header. Requires title or description to be set for the header to appear. Chart content is not slotted; use element.chartCanvas instead.
Code
HTML + JSInitialize Chart.js
<fresh-chart id="revenue-fc" title="Monthly revenue" description="MRR across all plans" height="220px"></fresh-chart> // Access the component's built-in canvas and pass to Chart.js var canvas = document.getElementById('revenue-fc').chartCanvas; new Chart(canvas, { type: 'line', data: { labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'], datasets: [{ data: [32, 35.8, 38.5, 41.2, 44.8, 48.3], borderColor: getComputedStyle(document.documentElement).getPropertyValue('--dv-1').trim(), backgroundColor: getComputedStyle(document.documentElement).getPropertyValue('--dv-1-subtle').trim(), fill: true, tension: 0.4, borderWidth: 2 }] }, options: { responsive: true, maintainAspectRatio: false, plugins: { legend: { display: false } } } });

<fresh-chart id="revenue-fc" title="Revenue" loading height="220px"></fresh-chart> // When data arrives: remove loading, then initialize Chart.js var fc = document.getElementById('revenue-fc'); fc.removeAttribute('loading'); new Chart(fc.chartCanvas, { type: 'line', data: { ... }, options: { responsive: true, maintainAspectRatio: false } });

Accessibility

Chart wrapper satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
chart contentThe built-in canvas carries aria-hidden="true" automatically. Use the description attribute to communicate the key data insight to screen readers; do not rely on chart graphics for meaning.
color-only seriesWhen rendering multi-series charts, do not rely on color alone to distinguish series. Add patterns, shapes, or labels directly in the chart so users with color vision deficiency can differentiate them.
loading stateThe shimmer overlay is aria-hidden="true". Announce loading status with a surrounding aria-live="polite" region if the chart is a primary content area.
