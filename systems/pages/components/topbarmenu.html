Topbar Menu

Text-first tab bar with a pill background on the active item. No underline, suited for top-level navigation, marketing pages, or any context where the underline style reads too heavy.

Topbar Menu states
Default (md) size="md" · Pill background on active tab, no underline. Ideal for section or top-level navigation.
With disabled disabled: true · Disabled tabs render at 38% opacity and block interaction.
Sizes size="sm" / "md" / "lg" · sm, md, and lg match the equivalent button heights. Padding, font, and radius scale together.

General fresh-topbar-menu
  • •Prefer fresh-topbar-menu for top-level or marketing navigation. Use fresh-tabs (underline style) for content area panels where the tab bar sits directly above panel content.
  • •Always set an initial active key so the component has a selected state on first render. An empty tab row with no selection appears broken.
  • •Listen to the change event to update the page view or URL. fresh-topbar-menu does not manage panel visibility itself.
  • •fresh-topbar-menu does not support badge. If badge counts are needed on the tabs, use fresh-tabs instead.
  • •Size should match the surrounding UI density: sm for compact toolbars, md for standard content pages, lg for marketing or landing page navigation.
  • •When tabs have secondary children (a two-level taxonomy), wire up a dropdown sub-nav at the page level: intercept the native click event on the component host to capture the click X position, then compare the active attribute before and after to detect which tab was selected. Show a position:fixed dropdown below the tab strip centred on the click position. The change event is not suitable for this because it does not fire on re-clicks of the already-active tab.
  • •Tabs with no secondary children should not show a dropdown. Suppress the dropdown and let the tab behave as a plain section switch.

Code
HTMLBasic usage with event listener
<fresh-topbar-menu id="nav-tabs" tabs='[ {"key":"overview","label":"Overview"}, {"key":"usage","label":"Usage"}, {"key":"tokens","label":"Tokens"} ]' active="overview"> </fresh-topbar-menu> <script> document.getElementById('nav-tabs').addEventListener('change', e => { console.log('Active tab:', e.detail.key); }); </script>
HTMLLarge with disabled
<!-- Large simple tabs for marketing page --> <fresh-topbar-menu size="lg" tabs='[ {"key":"features","label":"Features"}, {"key":"pricing","label":"Pricing"}, {"key":"changelog","label":"Changelog"}, {"key":"roadmap","label":"Roadmap","disabled":true} ]' active="features"> </fresh-topbar-menu>
HTMLDropdown sub-nav for secondary children
<!-- Dropdown sub-nav for tabs with secondary children --> <fresh-topbar-menu id="top-tabs" tabs='[ {"key":"home","label":"Home"}, {"key":"work","label":"Work"}, {"key":"settings","label":"Settings"} ]' active="home"> </fresh-topbar-menu> <div id="tab-dropdown" style="position:fixed;display:none;"></div> <script> /* Shadow button runs _select() synchronously — active attr is already updated by the time the host click listener fires. */ var CHILDREN = { work: ['My tasks', 'Projects', 'Calendar'], settings: ['Account', 'Security', 'Billing'] }; var tabs = document.getElementById('top-tabs'); var drop = document.getElementById('tab-dropdown'); var prevActive = tabs.getAttribute('active'), openKey = null, clickX = 0; function closeDrop() { openKey = null; drop.style.display = 'none'; } function openDrop(key, x) { var kids = CHILDREN[key]; if (!kids) { closeDrop(); return; } openKey = key; drop.innerHTML = kids.map(k => '<div>' + k + '</div>').join(''); drop.style.cssText = 'position:fixed;display:block;top:96px;left:' + (x-80) + 'px'; } tabs.addEventListener('click', e => { clickX = e.clientX; e.stopPropagation(); var now = tabs.getAttribute('active'); if (now !== prevActive) { prevActive = now; openDrop(now, clickX); } else { openKey === now ? closeDrop() : openDrop(now, clickX); } }); document.addEventListener('click', closeDrop); </script>
HTMLProgrammatic control
<!-- Programmatic control --> <fresh-topbar-menu id="st" tabs='[{"key":"a","label":"Tab A"},{"key":"b","label":"Tab B"}]' active="a"> </fresh-topbar-menu> <script> // Switch to Tab B programmatically document.getElementById('st').setAttribute('active', 'b'); </script>

Accessibility

Topbar Menu satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
roleTab list has role="tablist". Each button has role="tab" and aria-selected reflecting its active state.
keyboard navigationArrow Left/Right moves focus between tabs. Enter or Space activates the focused tab. Disabled tabs are skipped in the navigation cycle.
