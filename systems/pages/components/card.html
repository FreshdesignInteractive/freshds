General fresh-card
  • •Use fresh-card as the default surface for grouping related content on a page; do not build custom card surfaces with raw divs when this component is available.
  • •Add interactive only when the entire card is clickable as a unit. Do not use it for cards that contain individual interactive elements like buttons or links.
  • •Use href to make the card a native link; this automatically sets interactive behaviour and renders as an <a> tag for correct semantics.
  • •Choose padding based on content density: sm for compact lists, md (default) for standard content, lg for feature or marketing cards that need breathing room.
  • •Use the header slot for titles and toolbar actions; use the footer slot for confirmation buttons or pagination. Do not duplicate actions in both slots.

Accessibility

Card satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
Interactive cardsWhen using href, the card renders as an <a> with a visible focus ring. Ensure the card has a descriptive text label so screen readers can identify the link destination.
Nested actionsDo not nest focusable elements (buttons, links) inside an interactive card that also has an href. This creates nested interactive regions that violate HTML semantics.
Colour contrastCard uses semantic surface tokens. Ensure body text placed inside uses --text-primary or --text-secondary to maintain contrast against --surface-bg in both modes.
