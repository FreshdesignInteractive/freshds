Avatar

User identity display. Shows a photo when available, falling back to initials on error or when no source is provided. Initials color is deterministically derived from the name and stays consistent across sessions and themes.

General fresh-avatar
  • •Always provide a name attribute even when using src. It is used for initials fallback, color derivation, and the accessible aria-label.
  • •Use shape="square" for AI agents, bots, and system identities to visually distinguish them from human user avatars.
  • •Do not override avatar colors with custom CSS. The color palette is deterministic and fixed across all themes, ensuring each user always sees the same color for a given name.
  • •Use size="xl" for profile pages and account settings. Use size="md" or size="sm" for table rows, lists, and comment threads.
  • •Add a status attribute only when real-time presence data is available. Do not use status as a static decorative element.

Accessibility

Avatar satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
accessible nameThe inner div carries role="img" and aria-label set to the name attribute. Always provide a meaningful name.
initials decorationThe initials span has aria-hidden="true". Screen readers read the wrapping aria-label instead.
status dotStatus dot carries aria-label and title matching the status string (e.g. "online"). Sighted and AT users both receive the information.
color aloneAvatar identity color is supplementary. The name-based accessible label always conveys identity independently of color.
