General fresh-spinner
  • •Always pair the spinner with a nearby text label in the UI. The component has a built-in aria-label="Loading" but visible text provides better context for all users.
  • •Use size="sm" inline with body text (13-14px), md for standard UI regions, and lg only for prominent full-panel or full-page loading states.
  • •Use fresh-skeleton instead of spinner for page-level or content-area loads where the layout is known in advance. Spinner is for indeterminate durations only.
  • •Do not show a spinner for operations expected to complete in under 300ms. Flickering feedback is more disruptive than no feedback at all.
  • •For AI generation in progress, prefer fresh-thinking which includes an animated label. Reserve this spinner for generic async operations.

Accessibility

Spinner satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
status roleThe ring div carries role="status" and aria-label="Loading". Screen readers announce the loading state without requiring focus.
reduced motionConsider wrapping the spinner with a prefers-reduced-motion media query at the page level to pause animation for users with vestibular disorders.
