Checkbox

Binary on/off control for independent options. Use for settings, permissions, and multi-select lists where each item is independently toggleable.

Checkbox states
Unchecked · Default resting state. No value is selected.
Checked checked · The option is selected. The box fills with the interactive colour and shows a checkmark.
Indeterminate indeterminate · Mixed state: some but not all child items are checked. Used for "Select all" parent controls.
Disabled disabled · Interaction is blocked. Opacity drops to 40%. Can be combined with checked or indeterminate.

General fresh-checkbox
  • •Use fresh-checkbox for options that are independently toggleable. When the user must pick exactly one from a group, use fresh-radio instead.
  • •Always provide a label attribute. A checkbox without a visible label is inaccessible and violates WCAG 1.3.1.
  • •Use indeterminate only for a parent "Select all" control whose children are partially checked. Never use it to represent a loading or unknown state.
  • •Set value when the checkbox participates in a serialised form or when the change event payload needs to identify which option was toggled.
  • •In a list of checkboxes, group them under a visible heading or fresh-form-field label so the purpose of the group is clear to all users.

Accessibility

Checkbox satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
indeterminate stateThe indeterminate visual has no native ARIA equivalent. When used as a "Select all" parent, manage the child checkboxes in JS and update the parent's checked and indeterminate attributes to reflect the true aggregate state.
group labelA list of checkboxes must be wrapped in a semantic group with a visible heading so the purpose of the group is communicated to screen readers. A bare list of checkboxes without a group label fails WCAG 1.3.1.
