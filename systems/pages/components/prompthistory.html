Prompt History

Horizontally scrollable row of recent AI prompts rendered as clickable chips. Lets users quickly reuse previous queries without retyping.

Prompt history states
Default prompts array · Horizontal scrollable chip row with a "Recent" label and history icon. Prompts longer than max-chars are truncated with ellipsis; the full text is in the title tooltip.
Empty prompts='[]' · When no prompts are in the history the component renders a "No recent prompts" message in place of chips.
Many prompts 6+ items · With more prompts than the container can display, the row scrolls horizontally. The scrollbar is hidden; users swipe or drag to reveal more chips.
Short truncation max-chars="25" · Reduce max-chars to create more compact chips in narrow containers. Full text is always available in the tooltip on hover.

General fresh-prompt-history
  • •Load the prompts array from Supabase on page load, keyed to the authenticated user ID. Never read prompt history from localStorage - it does not persist across devices and leaks data in shared environments.
  • •Listen to the select event and populate the prompt input with detail.prompt immediately. Do not submit the prompt automatically - the user may want to edit it before sending.
  • •Cap the history at 10-20 items maximum. When a new prompt is submitted, prepend it to the array and trim to the cap. Do not show the same prompt twice - deduplicate before saving to Supabase.
  • •Place fresh-prompt-history directly above the fresh-prompt-input component so the spatial relationship between history and input is clear. Do not place it in a sidebar or below the input.
  • •Adjust max-chars to match the available container width. A good baseline is 40 characters for full-width inputs and 25 characters for narrow chat sidebars. Always test that chips do not overflow the container before shipping.
Attributes
AttributeValuesDefaultDescription
promptsJSON array of strings-Ordered list of recent prompts. Index 0 is shown first (most recent). Renders an empty state message when the array is empty.
max-charsnumber40Maximum character length displayed per chip before truncation with ellipsis. Full text is shown in the native title tooltip.
Events
EventDetailDescription
select{ prompt: string, index: number }Fires when a chip is clicked. prompt is the full original string (not truncated). index is the zero-based position in the array. Bubbles and is composed.
Code
HTMLBasic
<fresh-prompt-history prompts='[ "Summarize last quarter revenue", "Show active users by region", "Compare Q3 vs Q4" ]'> </fresh-prompt-history>
JSPopulate prompt input on select
const history = document.querySelector('fresh-prompt-history'); const input = document.querySelector('fresh-prompt-input'); history.addEventListener('select', (e) => { const { prompt } = e.detail; input.setAttribute('value', prompt); input.focus(); });
JSSupabase load and update
// Load from Supabase and prepend new prompts async function loadHistory(userId) { const { data } = await supabase .from('profiles') .select('prompt_history') .eq('id', userId).single(); const prompts = data?.prompt_history || []; document.querySelector('fresh-prompt-history') .setAttribute('prompts', JSON.stringify(prompts)); }
