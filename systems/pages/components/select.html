Select

Dropdown selection from a predefined list of options. Use when users must pick exactly one value from a known set that is too long for radio buttons.

General fresh-select
  • •Use fresh-select when users must choose exactly one value from a fixed list of 5 or more options. For fewer options, prefer fresh-radio groups.
  • •Always set a meaningful placeholder so the empty state is distinguishable from a selected value. Never leave the select blank with no hint.
  • •Wrap in fresh-form-field to provide a label and hint. Never render a bare fresh-select without an accessible label in a form context.
  • •Set error with a human-readable message when validation fails. Never use the error state for informational or warning messages.
  • •Match the size of the select to adjacent inputs in the same form row. Mixing sizes in a single row creates misaligned baselines.

Accessibility

Select satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
label associationWrap in fresh-form-field with a label attribute so the visible label is programmatically associated with the native select via the shadow DOM. Never rely on placeholder text as the only label.
error announcementThe error message container has role="alert", causing screen readers to announce it immediately when it appears. Only set error for true validation failures, not for hints or warnings.
