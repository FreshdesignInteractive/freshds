Progress

A horizontal bar that communicates completion percentage or indeterminate loading. Use for file uploads, multi-step flows, and background operations with measurable progress.

Progress states
Determinate value="0..100" · Shows a known completion percentage. The fill animates as value changes.
Indeterminate (no value attribute) · Animated sweep for operations where the total duration is unknown.
Sizes size="sm|md|lg" · sm (3px) for inline or compact contexts, md (5px) default, lg (8px) for prominent status areas.

General fresh-progress
  • •Omit value for operations where total duration is unknown. The component enters indeterminate mode automatically, showing an animated sweep instead of a percentage fill.
  • •Add label for operations longer than 3 seconds. Users need context about what is happening, not just a visual indicator.
  • •Add show-percent when precise progress data is available and meaningful to the user, such as file uploads, batch processing, or step completions.
  • •Use size="sm" for inline progress inside cards or table rows where space is limited. Use size="lg" only as a primary page-level indicator.
  • •Always update value incrementally as the operation progresses. Do not jump from 0 to 100 at completion; use a fresh-spinner instead for instant operations.

Accessibility

Progress satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
progressbar roleThe track carries role="progressbar" with aria-valuemin="0", aria-valuemax="100", and aria-valuenow set to the current value. In indeterminate mode, aria-label="Loading" is applied instead.
color onlyProgress value is always communicated numerically via aria-valuenow and optionally via the visible show-percent label, not through color alone.
