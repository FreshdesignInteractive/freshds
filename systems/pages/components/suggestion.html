Suggestion card

Proactive AI recommendation with accept and dismiss actions. Slides in with an entrance animation and removes itself from the DOM when dismissed. Use to surface insights and next steps without interrupting the main flow.

Suggestion card variants
With description · Full card with icon, title, supporting description, and custom accept label.
Minimal · Title and icon only. No description. Use for brief, self-explanatory prompts.
Different icons · The icon attribute accepts any Tabler icon class. Match the icon to the suggestion domain.

General fresh-suggestion-card
  • •Write the title as a specific observation, not a generic prompt. "Revenue is up 18% this week" is better than "View revenue data".
  • •Make accept-label a specific action verb, not "OK" or "Yes". "Show breakdown", "Investigate", and "Compare" tell users exactly what will happen.
  • •Always listen for both accept and dismiss events. When dismissed, record the user preference to avoid showing the same suggestion repeatedly in the same session.
  • •Show a maximum of 2-3 suggestion cards at a time. More than 3 cards in the same view reads as notification spam and reduces user trust in the AI.
  • •Pick an icon that represents the data or action domain, not just general AI icons. Use ti-chart-bar for analytics, ti-alert-circle for anomalies, ti-sparkles only for truly generic AI prompts.

Events
EventDetailDescription
accept-Fired when the user clicks the primary action button. Handle by navigating to the relevant view or triggering the AI action.
dismiss-Fired when the user clicks Dismiss. The element also removes itself from the DOM automatically after firing the event.
Code
HTMLFull card with description
<fresh-suggestion-card icon="ti-chart-bar" title="Revenue is up 18% this week" description="This is above your typical growth rate. Would you like a detailed breakdown?" accept-label="Show breakdown"> </fresh-suggestion-card>
JSHandling accept and dismiss
const card = document.querySelector('fresh-suggestion-card'); card.addEventListener('accept', () => { router.push('/analytics/revenue'); }); card.addEventListener('dismiss', () => { sessionStorage.setItem('suggestion-revenue-dismissed', '1'); });

Accessibility

Suggestion card satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
role noteThe card uses role="note" so screen readers announce it as supplementary information without interrupting the main content flow.
dismiss self-removalWhen dismissed, the element removes itself from the DOM. Ensure focus is managed back to a logical element so keyboard and screen reader users are not left in a dead zone.
