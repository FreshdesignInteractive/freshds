Feedback

Thumbs up/down rating row for AI responses. Collects a simple quality signal and optionally exposes a flag/report action for deeper issues.

Feedback states
Default neutral · No vote cast yet. Both thumbs appear in muted tertiary color with equal weight.
With flag show-flag · Adds a report button separated by a divider. Use when AI output could be harmful or incorrect and users need a reporting path.
Compact compact · Icon-only, no text labels. Use in tight layouts like chat message footers or narrow sidebars.

General fresh-feedback
  • •Place one fresh-feedback at the end of each AI response, not at the top. The user must read the response before they can meaningfully rate it.
  • •Use show-flag in contexts where AI output could be harmful, biased, or factually wrong. Do not add it in internal tooling where the audience is trusted and moderation is handled separately.
  • •Use compact in inline chat bubbles and narrow sidebars. Use the default labeled variant in review flows or dashboards where users are explicitly asked to evaluate responses.
  • •Listen to the rate event and persist the rating to Supabase immediately on each change. Do not wait for a form submit. Handle detail.value === null to clear a previously stored rating when the user deselects.
  • •Do not disable the component after a vote is cast. Toggling is intentional and lets users change their mind. Show a confirmation toast only if the rating is stored for model-training purposes.
Attributes
AttributeValuesDefaultDescription
show-flagboolean-Shows a flag/report button after a divider. Fires the flag event when clicked.
compactboolean-Icon-only mode. Hides text labels and reduces button padding for tight layouts.
Events
EventDetailDescription
rate{ value: 'up' | 'down' | null }Fires on every thumb click. value is null when the same thumb is clicked again to deselect. Bubbles and is composed.
flag{}Fires when the flag button is clicked (requires show-flag). No detail payload. Bubbles and is composed.

JSEvent handling
const fb = document.querySelector('fresh-feedback'); fb.addEventListener('rate', (e) => { const { value } = e.detail; // 'up', 'down', or null if (value) saveFeedback(value); else clearFeedback(); }); fb.addEventListener('flag', () => { openReportDialog(); });
