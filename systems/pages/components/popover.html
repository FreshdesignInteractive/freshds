Popover

Floating content panel anchored to a trigger element. Wraps any trigger in the trigger slot and any content as default slot. Clicking the trigger opens the panel; clicking outside or pressing Escape closes it.

Popover placements
Bottom (default) placement="bottom" · Panel opens below the trigger, left-aligned. Default placement. Automatically repositions to avoid viewport clipping.

General fresh-popover
  • •Always use the trigger slot for the trigger element. Do not attach click handlers externally to open a popover - the component manages open/close state internally.
  • •Use fresh-popover for contextual menus, quick-edit panels, and filter dropdowns anchored to a specific element. For global modals or drawers that are not anchored to a trigger, use fresh-modal or fresh-drawer instead.
  • •Choose placement based on the available space around the trigger, not aesthetics. The component adjusts horizontally to stay within the viewport, but set the primary direction deliberately based on the trigger's position in the layout.
  • •Keep popover content lightweight. Avoid putting forms, multi-step flows, or large amounts of scrollable content inside a popover. Use a drawer or modal for complex or tall content.
  • •The component fires open and close events. Use the close event to clear temporary state (e.g. a search input inside the popover) when it is dismissed, not on every interaction inside the panel.

<fresh-popover placement="right" offset="8"> <fresh-button slot="trigger" variant="ghost" size="sm"> <i class="ti ti-dots-vertical"></i> </fresh-button> <div style="padding:12px 16px;min-width:200px"> <!-- panel content --> </div> </fresh-popover>

const pop = document.querySelector('fresh-popover'); pop.addEventListener('open', () => { // load data or set focus inside the panel }); pop.addEventListener('close', () => { // clear ephemeral state });

Accessibility
ConcernRequirement
dialog roleThe floating panel has role="dialog". When the panel opens, move focus to the first interactive element inside it so keyboard users do not have to tab through the rest of the page to reach the panel content.
escape dismissalPressing Escape while the panel is open closes it and returns focus to the trigger button. This is required for keyboard accessibility and is built into the component.
