Diff Viewer

Side-by-side or inline comparison of original and AI-edited content. Word-level diffing highlights additions in green and deletions in red. Accept or reject the revision with one click.

Diff viewer states
Side-by-side (default) mode="side-by-side" · Original on the left, revised on the right. Deletions highlighted in the left panel, additions in the right.
Inline diff mode="inline" · Deletions and additions shown in a single panel. Good for compact layouts or small edits.
AI action rules
Click any rule to edit
General fresh-diff-viewer
  • •Always surface the diff viewer before applying an AI edit. Never apply rewrites silently: the user must Accept or Reject every change.
  • •Use mode="side-by-side" for longer content blocks where tracking paragraph-level changes is important. Use mode="inline" for short snippets or dense layouts.
  • •Listen to the accept event and replace the original content in your data layer. Listen to reject and restore the original. Never leave the diff viewer showing a stale state.
  • •Pass the untruncated original and revised strings. Do not summarize or abbreviate: the user needs to see the full context to make an informed decision.
  • •After the user accepts or rejects, remove or hide the diff viewer. Do not leave it visible in a resolved state as that creates ambiguity about document status.
Attributes
AttributeValuesDefaultDescription
originalstring-The original (before) text. Required.
revisedstring-The AI-edited (after) text. Required.
modeside-by-side inlineside-by-sideDiff display layout. Side-by-side shows two panels; inline shows changes within a single panel.
Events
EventDetailDescription
accept-Fired when the user clicks "Accept". Apply the revised version in your data layer.
reject-Fired when the user clicks "Reject". Restore the original in your data layer.
Code
HTMLSide-by-side diff
<fresh-diff-viewer
  original="The quick brown fox jumps over the lazy dog."
  revised="The swift brown fox leaps over the sleeping dog."
></fresh-diff-viewer>
HTMLInline diff
<fresh-diff-viewer
  mode="inline"
  original="Results are mostly accurate."
  revised="Results are highly accurate across all query types."
></fresh-diff-viewer>
JSHandle accept and reject
const viewer = document.querySelector('fresh-diff-viewer');
viewer.addEventListener('accept', () => {
  doc.content = viewer.getAttribute('revised');
  viewer.remove();
});
viewer.addEventListener('reject', () => {
  viewer.remove();
});
