Data table

Enhanced data grid with full-text search, column sorting, row selection with bulk actions, and single-row highlight. Columns and data are passed as JSON attributes.

Data table states
Searchable + sortable searchable · Search filters all columns in real time. Click sortable column headers to toggle asc/desc. Fires a sort event on each change.
Row selection selectable · Adds row checkboxes and a select-all. When rows are selected, the bulk actions bar appears. Fires selection-change with selected indices.
Delete selected
Row highlight highlightable · Click a row to highlight it for focus. Click again to clear. Fires row-highlight with the row data and index. Only one row can be active at a time.

General fresh-data-table
  • •Always define column keys that exactly match the data object keys. Mismatched keys render empty cells with no error.
  • •Use selectable only when there is at least one meaningful bulk action. Avoid adding checkboxes without a corresponding slot action.
  • •Do not use both selectable and highlightable simultaneously. They serve different interaction models: multi-select for bulk operations, single-highlight for detail panels.
  • •Set align="right" on numeric columns (tokens, cost, count). Left-align all text columns. Right-aligned numbers are easier to scan and compare visually.
  • •Pre-format all values before passing to data. The table does not apply number, date, or currency formatting. Format strings like "1,284" and "$0.18" before binding.

Events
EventDetailDescription
sort{ key, direction }Fired when a sortable column header is clicked. direction is "asc" or "desc".
selection-change{ selected: number[] }Fired when row selection changes. selected is an array of selected row indices.
row-highlight{ row: object|null, index: number|null }Fired when a row is highlighted or cleared. row is null when the highlight is cleared.

Accessibility

Data table satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
keyboard sortingSortable column headers are clickable via mouse. Consider adding tabindex="0" and a keydown handler for full keyboard access in production integrations.
checkbox groupCheckboxes use native input[type="checkbox"] elements. The select-all sets indeterminate via JS to communicate partial selection state to screen readers.
bulk action barThe bulk count label communicates how many rows are selected. Ensure bulk action buttons carry descriptive labels (e.g. "Delete 3 selected rows", not "Delete").
