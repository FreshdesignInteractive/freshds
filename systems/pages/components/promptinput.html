Prompt input

The signature input for AI interactions. Designed for natural language queries, it signals to users that they are talking to an intelligent system, not filling out a form.

Prompt input states
Default · Resting state with sparkle icon indicating AI capability.
Focused focused · Focus ring visible, indicating active input. Renders with border-color and shadow applied.
With attach and voice show-attach show-voice · Full toolbar mode with file attachment and voice input buttons enabled.
Disabled disabled · Disables the input and all action buttons. Use when AI is unavailable or a conversation is locked.

General fresh-prompt-input
  • •Always provide a contextual placeholder that matches the domain. "Ask anything about your sales data..." is better than generic "Type here...".
  • •Only add show-attach and show-voice when those capabilities are fully implemented in the product. Never show affordances that do nothing.
  • •Set disabled when the AI model is unavailable, context is full, or submission is in progress. Always pair with a visible explanation near the input.
  • •Listen for the fresh-submit event to capture the prompt value. The component clears itself after dispatch, so store the value immediately in the event handler.
  • •Use this component only for natural language AI queries, not for search fields or standard form inputs. Use fresh-input for non-AI text entry.

Events
EventDetailDescription
fresh-submit{ value: string }Fired on send button click or Enter key. The input clears itself after dispatch.
fresh-attach-Fired when the attach button is clicked. Requires show-attach.
fresh-voice-Fired when the microphone button is clicked. Requires show-voice.
Code
HTMLBasic usage
<fresh-prompt-input placeholder="Ask anything about your data..."></fresh-prompt-input>
HTMLWith attach and voice buttons
<fresh-prompt-input show-attach show-voice placeholder="Ask anything..."></fresh-prompt-input>
JSHandling the submit event
const input = document.querySelector('fresh-prompt-input'); input.addEventListener('fresh-submit', (e) => { const userPrompt = e.detail.value; sendToAI(userPrompt); });

Accessibility

Prompt input satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
keyboard submissionEnter key submits the prompt. Shift+Enter inserts a newline if multi-line input is added. Screen reader users must be able to submit without a pointer device.
send button labelThe send button carries aria-label="Send". If the icon-only button is used, this label is the only accessible name available to assistive technology.
