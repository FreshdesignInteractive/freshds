Table

Structured data display with click-to-sort columns and horizontal scroll on overflow. Use for tabular data where row count is bounded and relationships between columns matter. For searchable, selectable, or row-clickable tables, use fresh-data-table.

Table variants
Default with sorting · Standard table with sortable columns. Click any column marked sortable to toggle asc/desc order.
Striped striped · Alternating row backgrounds improve scanability in dense tables with many rows.
With caption caption="..." · Accessible caption is visually hidden but announced by screen readers as the table label.

General fresh-table
  • •Use fresh-table for static or server-sorted data. Use fresh-data-table when you need client-side search, row selection, or row highlighting.
  • •Only mark columns as sortable: true when sorting that column actually makes sense for the data type. Sorting a column of avatar images or icon badges is meaningless.
  • •Add striped for tables with more than 8-10 rows. For shorter tables, use hover states alone to guide the eye across rows.
  • •Always set align: "right" on numeric columns. Numbers right-aligned let users scan and compare values at a glance. Left-aligned numbers are harder to parse.
  • •Always provide a caption describing the table contents. It is visually hidden but critical for screen reader users to understand the table before navigating into it.

Code
HTMLBasic sortable table
<fresh-table columns='[ {"key":"name", "label":"Name", "sortable":true}, {"key":"role", "label":"Role"}, {"key":"status", "label":"Status"}, {"key":"joined", "label":"Joined", "sortable":true, "align":"right"} ]' data='[...]' caption="Team members"> </fresh-table>
JSServer-side sort handler
const table = document.querySelector('fresh-table'); table.addEventListener('sort', (e) => { const { key, direction } = e.detail; fetchData({ sortBy: key, order: direction }); });

Accessibility

Table satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
captionAlways provide a caption attribute. It is set as both aria-label on the table element and as a visually hidden <caption> element for maximum compatibility.
sort stateSortable headers use cursor: pointer and change color when active. Future enhancement: add aria-sort attribute to the active th for full screen reader sort state announcement.
