Empty State

Zero-state placeholder shown when a list, table, or container has no content. Always explains why the space is empty and, where appropriate, offers a clear next action.

Empty state variants
Default icon + title + description · Icon, title, and supporting description. Use for inbox-zero, no-data, and permission-denied states.
With action slot="action" · Add a CTA via the action slot when there is a direct path for the user to fill the empty space themselves.
Ask AI
No results icon="ti-search" · Use the search icon and a ghost action button when results are filtered out, to let users clear filters quickly.
Clear filters
Minimal no icon · Title and description only, no icon. Use in dense table rows or sidebar panels where vertical space is limited.

General fresh-empty-state
  • •Always provide a description that explains why the space is empty. "No data" alone is not helpful - tell the user what normally appears here and how it gets populated.
  • •Add the action slot only when there is a concrete step the user can take right now. Do not add a CTA if the empty state is caused by filters or permissions the user cannot change in context.
  • •Choose the icon to match the content type, not the action: use ti-inbox for messages, ti-search for search, ti-file for documents. Do not use generic icons like ti-alert-circle for empty states.
  • •Omit the icon in dense or narrow layouts (e.g. sidebar lists, inline table cells). The icon attribute is optional - a title and description alone work well for constrained spaces.
  • •Do not confuse empty state with error state. If data failed to load, use fresh-alert variant="danger" with a retry action, not an empty state component.
