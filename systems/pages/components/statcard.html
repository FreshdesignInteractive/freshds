Stat card

KPI display card combining a primary value, label, optional trend indicator, and icon. Use in dashboard grids to surface key metrics at a glance.

Stat card states
With trend trend="12.4" · Positive trend shows green up arrow, negative shows red down arrow. Trend value is the percentage change.
No trend trend omitted · When trend is omitted, only the value and label are shown. Use for static or non-comparative metrics.
No icon icon omitted · Icon is optional. Omit when the metric is self-explanatory or when visual density needs to stay low.

General fresh-stat-card
  • •Use stat cards in groups of 3 to 4 in a responsive row. Fewer than 3 leaves too much visual imbalance; more than 4 overwhelms the dashboard header.
  • •Only set trend when you have a genuine comparison value. Do not fabricate trend data or default it to zero when data is unavailable.
  • •Always pair trend with trend-label to give context: "vs last month", "this week", "since yesterday".
  • •Keep the value short and already formatted: "$24,580" not "24580". The card does not apply number formatting.
  • •Use Tabler icon classes for the icon attribute (e.g. ti-users). Choose icons that reinforce the metric category, not decorative ones.
Attributes
AttributeValuesDefaultDescription
valuestring-Primary metric value. Pre-format with units, currency, and separators before passing.
labelstring-Metric name displayed above the value as a muted caption.
trendnumber-Percentage change. Positive = up (green), negative = down (red). Omit to hide the trend row entirely.
trend-labelstring-Context phrase shown after the trend percentage, e.g. "vs last month".
iconTabler class, e.g. ti-users-Icon displayed top-right in a subtle rounded badge. Omit to remove the icon area.

Accessibility

Stat card satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
trend directionTrend uses color (green/red) and a directional arrow SVG. Both signals are present, satisfying WCAG 1.4.1 (use of color). The SVG arrows are aria-hidden and the wrapping trend text provides the numeric value.
value contrastValue uses --text-primary against --surface-bg. All theme configurations must maintain a 4.5:1 minimum contrast ratio for this pairing.
