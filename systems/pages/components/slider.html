Slider

Range input for selecting a numeric value within a continuous or stepped range. Use for settings like volume, brightness, or budget where an approximate value is acceptable.

Slider states
Default · Continuous range from 0 to 100. Default value is 50. The filled track shows position.
With step step="1" · A discrete step constrains the thumb to specific values. Useful for whole numbers or predefined intervals.
Disabled disabled · Interaction blocked. Opacity drops to 40% and the cursor changes to not-allowed.

General fresh-slider
  • •Use fresh-slider when approximate values are acceptable. If the user needs to enter an exact number, use fresh-input type="number" instead, or pair the slider with a numeric input that syncs bidirectionally.
  • •Always display the current value near the slider so users know what they have selected. The slider itself does not render a value label.
  • •Use the input event for live preview updates (e.g. volume preview) and the change event to commit the value to state. Avoid heavy operations in the input handler.
  • •Set meaningful min, max, and step values that match the domain. For 1-5 star ratings, use min="1" max="5" step="1". Do not default to 0-100 when the domain has a narrower natural range.
  • •Wrap in fresh-form-field with a label describing what the slider controls. Never rely on position alone to communicate the slider's purpose.

Accessibility

Slider satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
value announcementThe native range input announces the current value on change. Always provide a visible numeric value display adjacent to the slider so sighted users who do not interact via keyboard also see the selected number.
label associationWrap in fresh-form-field with a descriptive label attribute. The label is required for screen readers to announce what the slider controls. Do not use placeholder text or nearby headings as a substitute.
