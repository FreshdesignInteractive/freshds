Pagination

Page-number navigation for tables and lists. Renders previous/next arrow buttons with numbered page buttons and ellipsis truncation for large page ranges.

Pagination states
First page page="1" total="10" · Previous arrow is disabled. Page 1 is highlighted as the active page.
Middle page page="5" total="10" · Both arrows are active. The current page is highlighted with the interactive fill color.
Last page page="10" total="10" · Next arrow is disabled. Page 10 is highlighted as the active page.
With ellipsis page="8" total="50" · For large page counts the component automatically inserts ellipsis. Siblings either side of the current page are shown.
Small size="sm" · 28px button height for compact layouts like below-table toolbars or card footers.
Extended siblings siblings="2" · Increase the siblings attribute to show more page numbers on either side of the active page before ellipsis appears.

General fresh-pagination
  • •Always set total to the actual total page count, not the total item count. Calculate pages server-side as Math.ceil(totalItems / pageSize) before passing to the component.
  • •Listen to the change event and fetch the new page of data immediately. Update the page attribute on the component after the data loads to keep the display in sync with the actual content shown.
  • •Use size="sm" when the pagination sits inside a card footer, toolbar, or any container shorter than 48px. Use the default md size for standalone below-table placement.
  • •Do not show pagination for datasets under 25 items that fit on a single page. Pagination on a one-page result set adds navigation overhead with no benefit.
  • •Persist the current page to the URL query string (e.g. ?page=3), not localStorage. This allows users to share or bookmark a specific result page and for the browser back button to restore position.

Events
EventDetailDescription
change{ page: number }Fires when a page button or arrow is clicked. page is the 1-based target page number. Does not fire if the current page is clicked again. Bubbles and is composed.

JSFetching page data
const pag = document.querySelector('fresh-pagination'); pag.addEventListener('change', async (e) => { const { page } = e.detail; const results = await fetchPage(page, PAGE_SIZE); renderTable(results); pag.setAttribute('page', page); });
