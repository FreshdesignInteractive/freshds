Citation Chip

Inline reference chip linking AI output to a source document. Renders as a non-interactive span or a clickable anchor depending on whether an href is provided.

Citation chip states
Source only source="Q3 Report" · Non-interactive chip showing the source name inline with text.
Revenue grew 12.4% this quarter driven by enterprise demand.
Source with page number source="Annual Report" page="14" · Page reference appended after a separator inside the chip.
APAC growth accelerated in H2 outpacing all other regions.
Linked chip href="/docs/q3" · Clickable anchor with hover state. Opens in a new tab.
Enterprise churn fell to 2.1% the lowest in four years.
Multiple inline citations · Several citations placed throughout a paragraph to attribute each claim.

Revenue grew 12.4% driven by APAC and new enterprise deals closed in September.

Click any rule to edit
General fresh-citation-chip
  • •Insert citation chips immediately after every claim that the AI sourced from a document. Never batch all citations at the end of a paragraph.
  • •Always provide href when the source is directly accessible. Users expect to click a citation to verify a claim.
  • •Set page to the specific section or page number whenever available. Vague citations reduce trust in AI output.
  • •Use short, recognizable source names: "Q3 Report" not "2024_Q3_Revenue_Analysis_Final_v2.pdf". Truncate programmatically if needed.
  • •Limit to three or four citations per paragraph. More than that signals the AI is over-attributing and disrupts reading flow.
Attributes
AttributeValuesDefaultDescription
sourcestringSourceDocument or source name displayed inside the chip.
pagestring-Page number or section reference. Shown after a separator inside the chip.
hrefstring-When provided, the chip renders as a link and opens the source in a new tab. Without it the chip is non-interactive.

JSInject from API citations
// Replace citation placeholders from API response
const chips = response.citations.reduce((t, c) => {
  const chip = `<fresh-citation-chip source="${c.source}" page="${c.page}" href="${c.url}"></fresh-citation-chip>`;
  return t.replace(c.placeholder, chip);
}, response.text);
bubble.innerHTML = chips;
