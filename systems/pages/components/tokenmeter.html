Token meter

Visual indicator of AI context window consumption. The fill color is brand-colored at normal usage, shifts to amber at the warning threshold (default 80%), and turns red at critical usage (95%). Two display modes: full (label + count + bar) and compact (bar + percentage only).

General fresh-token-meter
  • •Always set both used and total to match the actual model context window. Never use made-up numbers. The meter should reflect real API usage.
  • •Place the token meter in a persistent location such as a chat sidebar, navbar footer, or session panel. It should always be visible while a conversation is active, not hidden in a settings menu.
  • •When the meter hits the warning threshold, surface a contextual message near the prompt input explaining that the context window is nearly full and suggesting the user start a new conversation.
  • •Use compact mode in navbars and sidebars where vertical space is limited. Use the full mode in conversation panels where the token count context is meaningful to the user.
  • •Update used after every model response, not just at the end of the conversation. Token count should feel live, giving users real-time awareness of context consumption.

Accessibility

Token meter satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
meter roleThe wrapper uses role="meter" with aria-valuenow, aria-valuemin, aria-valuemax, and aria-label set to "Token usage: {pct}%". Screen readers announce the current percentage.
color-only warningColor change at the warning threshold is not sufficient alone. Pair the token meter with a visible text warning when usage exceeds 80% so users who cannot perceive color changes still receive the alert.
