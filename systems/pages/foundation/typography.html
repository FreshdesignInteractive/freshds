Generation rules --font-sans · --font-mono
  • •Always set font-family using var(--font-sans) or var(--font-mono). Never hardcode a font name like "Inter" or "JetBrains Mono" in component code. The customer may have configured a different typeface and the token is the only correct reference.
  • •Use var(--font-mono) for all code snippets, token names, data values, numeric IDs, and timestamps. Use var(--font-sans) for everything else including labels, descriptions, headings, and button text.
  • •Set font size using var(--font-size-md) (14px) as the default body text. Use var(--font-size-sm) (13px) for secondary labels. Use var(--font-size-xs) (12px) for captions and timestamps. Never set font-size in px or rem directly; always use the scale token.
  • •Use font-weight 400 for body, 500 for labels and interactive elements, 600 for headings and emphasis. Never use 700 or higher. Never use 300 (Light) for text smaller than 16px as it fails contrast at small sizes.
  • •Set line-height to 1.5 for body paragraphs, 1.6 for help text and descriptions, 1.2 for headings and display text. Never use unitless values below 1.2 or above 1.8 on any text element.
  • •Use var(--text-primary) for main content, var(--text-secondary) for supporting text, var(--text-tertiary) for captions and placeholders. Never set text color as a raw hex; always use a semantic text token so dark mode works automatically.

Accessibility
ConcernRequirement
contrast Body text (14px regular) requires 4.5:1 contrast. Large text (18px+ or 14px bold) requires 3:1. Use var(--text-primary) on var(--surface-bg) by default; the DS token pairs are pre-verified at both contrast levels.
minimum size Do not render interactive text (links, buttons) below 12px (--font-size-xs). Captions and decorative labels may use 10px (--font-size-3xs) if they carry no interactive or essential meaning.
line height WCAG 1.4.12 requires line-height at least 1.5x font-size for body text. FreshDS defaults are 1.5 (body) and 1.6 (descriptions). Never override with a value below 1.5 on paragraph-length content.
letter spacing WCAG 1.4.12: user agents may apply 0.12em letter-spacing without loss of content or function. Avoid letter-spacing: normal combined with very tight custom tracking; keep tracking at or above -0.02em.
