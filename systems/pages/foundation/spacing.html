General --space-{n}
  • •Always use spacing tokens (--space-1 through --space-12) for all padding, gap, and margin values. Never write hardcoded px values for spacing in component or layout CSS.
  • •Only the nine defined steps are valid: 1, 2, 3, 4, 5, 6, 8, 10, 12. Do not interpolate or invent intermediate values such as --space-7 or --space-9.
  • •Apply the containment rule: inner item gaps should be one token step smaller than the surrounding container padding. A card with padding: var(--space-5) uses gap: var(--space-4) between its children.
  • •--space-4 (16px) is the default component padding. Use --space-5 or --space-6 for cards and panels. Use --space-3 or smaller for compact or dense UI variants.
  • •Page-level layout uses --space-8 (32px) as the standard section gap. Between major page sections use --space-10 or --space-12. Never use spacing tokens for fixed widths or heights.
  • •Spacing tokens are for layout rhythm only. Never assign them to width, height, font-size, border-radius, or border-width. Those dimensions have their own token families.
