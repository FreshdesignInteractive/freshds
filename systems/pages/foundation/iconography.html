AI action rules
Click any rule to edit
General ti ti-{name}
  • •Always pair an icon with a visible text label for actions. A standalone icon is only acceptable for universally understood symbols (close, search) and only when space is critically constrained. Always include aria-label on the parent button when the label is hidden.
  • •Size icons to match the surrounding text context: 14px alongside small body copy, 16px as the default inline size, 20px for medium-emphasis elements, 24px for primary navigation, 32px for empty states and hero callouts.
  • •Use icons from the Tabler library only. Never inline custom SVGs or reference other icon libraries. The class pattern is always ti ti-{name}.
  • •Color icons with DS semantic tokens, never hardcoded hex. Use --text-secondary for decorative icons, --text-primary for active/selected icons, --color-danger for destructive action icons.
  • •Use AI-specific icons (ti-sparkles, ti-brain, ti-wand, ti-circuit-board) exclusively for AI-initiated actions and AI UI components. Do not use them for general actions to avoid misleading users about feature origin.
Code
HTMLBasic icon
<i class="ti ti-sparkles"></i>
HTMLCustom size and color token
<i class="ti ti-star" style="font-size:20px;color:var(--text-secondary)"></i>
HTMLIcon with label (decorative)
<!-- Icon alongside label — mark decorative --> <button> <i class="ti ti-download" aria-hidden="true"></i> Export </button>
HTMLIcon-only button
<!-- Icon-only button — label on the button itself --> <button aria-label="Close"> <i class="ti ti-x" aria-hidden="true"></i> </button>
Accessibility

Icons are decorative by default. Accessibility is the responsibility of the element that contains them.

ConcernRequirement
decorative icons Add aria-hidden="true" to the <i> element when an adjacent text label already describes the action. This prevents screen readers from announcing the icon glyph name.
icon-only buttons When no visible label is present, the parent <button> must carry aria-label="Action name". The icon always gets aria-hidden="true".
color as meaning Icons used to convey status (error, success, warning) must not rely on color alone. Pair with a text label or shape distinction so the meaning is available without color perception.
