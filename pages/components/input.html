General fresh-input
  • •Use <fresh-input> for all single-line text collection: search fields, form fields, filters, inline edits.
  • •Always pair with a visible <label> or pass aria-label directly on the element. Never leave an input without an accessible name.
  • •Use the error prop for inline validation feedback. Do not render separate error paragraphs outside the component; they will not be associated with the input for screen readers.
  • •Use size="sm" inside table rows, filter bars, and toolbars to match the density of surrounding elements. Default md for standalone forms.
  • •Set type correctly: email, password, number, search unlock native browser behaviours (autocomplete, input mode, validation). Never use type="text" for fields where a more specific type exists.
Attributes
Attribute Values Default Description
type text email password number search text Native input type. Affects keyboard, autocomplete, and browser validation behaviour.
size sm md lg md Height: sm 28px, md 34px, lg 40px. Matches Button size scale for inline composition.
placeholder string - Hint text shown when the field is empty. Not a substitute for a label.
value string - Initial value. Also readable and writable via the .value property.
icon Tabler class e.g. ti-search - Renders a leading icon inside the field. Purely decorative — do not use as the sole label.
error string - Error message rendered below the field. Sets aria-invalid="true" and aria-describedby on the native input.
clearable boolean - Shows an x clear button when the field has a value. Fires a change event on clear.
disabled boolean - Blocks all interaction. Renders at reduced opacity. Sets disabled on the native input.
readonly boolean - Displays the value but prevents editing. The field remains focusable and copyable.

Accessibility

Input satisfies all universal accessibility concerns. Component-specific concerns are below.

Concern Requirement
label association The component renders a native <input> inside shadow DOM. Use a visible <label for> paired via the host element's id, or pass aria-label directly on <fresh-input>. Placeholder text alone is not sufficient.
error announcement The error prop sets aria-invalid="true" and connects the error message via aria-describedby. Screen readers will announce the error after the field label when the user reaches the field.
clearable button The clear button is rendered with aria-label="Clear" and is keyboard-reachable. It is hidden via aria-hidden when the field is empty so it does not pollute the tab order.
