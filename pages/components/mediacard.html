Media Card

Card with a prominent thumbnail area and a text footer. Designed for pattern libraries, image galleries, and any grid of visual items where a preview is the primary identifier.

Media card variants
Default title + description · Slotted thumbnail with a title and optional description footer. Hover lifts the card with a shadow and 2px translate.
Clickable link href · When href is set the card renders as an <a> tag. Supports target and rel automatically for _blank.
Without description title only · Omit the description for compact grids where the title alone identifies the item.
Custom ratio ratio="4/3" · Override the default 16/10 thumbnail ratio. Use ratio="1/1" for square previews or ratio="4/3" for traditional screenshots.

General fresh-media-card
  • •Always provide a title. The title is required for accessibility and is the primary label for the card when the thumbnail cannot be seen (low vision, image failure).
  • •Use the slot="thumb" for gradient or illustrative previews, and use src only when you have a real image URL. Never use src with a placeholder color - use the slot instead.
  • •Set href when the card should navigate. Do not wrap a non-link card in an <a> tag externally - the component handles link rendering internally based on whether href is present.
  • •Keep description to a single short line. The text is truncated with ellipsis at the card width so long strings will be cut off. If more detail is needed, open a drawer or modal on click.
  • •Use a consistent ratio across all cards in a grid. Mixed ratios create uneven rows and break the visual rhythm. Choose one ratio per grid and apply it to every card in that context.
Attributes
Attribute / SlotValuesDefaultDescription
titlestring-Card label shown in the footer. Required. Truncated with ellipsis when the card is too narrow.
descriptionstring-Optional secondary line below the title. Truncated with ellipsis.
srcstring (URL)-Image URL. When set, renders an <img> with loading="lazy". Overrides the thumb slot.
hrefstring (URL)-When set, the card renders as an <a> tag and is keyboard-focusable as a link.
targetstring-Link target, e.g. _blank. Automatically adds rel="noopener noreferrer" when _blank.
ratioCSS ratio string16/10Thumbnail aspect ratio as a CSS aspect-ratio value, e.g. 16/9, 4/3, 1/1.
slot="thumb"element-Custom thumbnail content. Fill 100% width and height. Used when src is not provided.

<!-- Image URL thumbnail with link --> <fresh-media-card src="screenshots/dashboard.png" title="Dashboard" description="Analytics overview" href="/patterns/dashboard" ></fresh-media-card>

<!-- Square ratio, no description --> <fresh-media-card title="Avatar" ratio="1/1" style="width:180px"> <div slot="thumb" style="background:var(--surface-subtle);height:100%"></div> </fresh-media-card>

Accessibility
ConcernRequirement
image alt textWhen src is set the generated <img> uses the title attribute as its alt. Ensure the title text describes the image content, not just the card label.
link semanticsWhen href is set the card renders as a native <a> and is keyboard-navigable with Tab/Enter. Do not add an extra click handler on the card element when href is already set.
