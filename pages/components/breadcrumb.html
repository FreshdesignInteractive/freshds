Breadcrumb

Hierarchical path indicator showing the user's location within the application. Previous levels are linked; the current page is non-interactive and bold.

Breadcrumb states
Short trail 2 items · Minimal two-level path. One linked ancestor, one current page crumb.
Deep trail 4 items · Multi-level hierarchy. All ancestors linked with chevron separators.
Sizes size="sm" / "md" · sm at 11px for compact page headers, md (default) at 13px for standard layouts.
Unlinked ancestor no href · An item without an href renders as a plain text crumb, not a link. Useful for logical groupings without a dedicated URL.

General fresh-breadcrumb
  • •The last item in the items array always represents the current page. Omit href from it. The component automatically renders it non-interactive with aria-current="page".
  • •Provide href on every ancestor item that has a real destination. If a level in the hierarchy has no URL, omit href to render it as plain text.
  • •Use size="sm" when placing the breadcrumb inside a page header alongside a large <h1>. Use the default md size in standalone or toolbar contexts.
  • •Do not include the application root (e.g. "App") as a breadcrumb item unless it is genuinely navigable and users need to return to it. Keep trails to five items or fewer for legibility.
  • •Use the exact page title as the breadcrumb label for the current item. Abbreviations or truncated labels cause confusion between the breadcrumb and the visible page heading.

Accessibility

Breadcrumb satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
landmarkRenders as <nav aria-label="Breadcrumb"> with an ordered list inside. Screen readers announce it as a navigation landmark distinct from the primary nav.
current pageThe last crumb gets aria-current="page" automatically. Do not add this attribute manually on the parent element.
separatorThe SVG chevron separator has aria-hidden="true" so it is not read aloud between crumb labels.
