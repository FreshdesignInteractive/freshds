AI Mode Toggle

Global switch for enabling or disabling AI features across an application. Animated pill toggle with a sparkle icon knob and a glowing active state. Available in two sizes.

AI mode toggle states
Off (default) · AI features are disabled. Track is muted, knob is inactive.
On on · AI features are active. Track glows with the brand interactive color.
Custom label label="AI Copilot" · Adapt the label to the specific AI feature being toggled.
Small size size="sm" · Compact variant for tight layouts such as settings rows or toolbar strips.
In a settings panel · Small toggles paired with a label and description row in a settings list.

General fresh-ai-mode-toggle
  • •Place the AI mode toggle in a persistent location: the top navigation bar or a settings panel. Do not scatter individual AI toggles across unrelated screens.
  • •Listen to the change event and persist the user's preference to Supabase immediately. Never rely on in-memory state across page loads.
  • •Adapt the label to the specific AI feature it controls. "AI Copilot", "Smart Suggestions", and "Auto-complete" are clearer than the generic "AI mode" in feature-specific contexts.
  • •Use size="sm" inside settings rows or toolbars. Use the default md size as a standalone top-level control.
  • •When AI mode is turned off, immediately hide or disable all AI-driven UI elements. Do not leave orphaned AI outputs or streaming states visible.

Code
HTMLActive toggle with custom label
<fresh-ai-mode-toggle
  label="AI Copilot"
  on
></fresh-ai-mode-toggle>
JSPersist preference to Supabase
document.querySelector('fresh-ai-mode-toggle')
  .addEventListener('change', async (e) => {
    const { data: { user } } = await supabase.auth.getUser();
    if (!user) return;
    await supabase.from('profiles')
      .update({ ai_mode: e.detail.on })
      .eq('id', user.id);
  });
HTMLSmall size for settings row
<fresh-ai-mode-toggle
  size="sm"
  label="AI Copilot"
  on
></fresh-ai-mode-toggle>
