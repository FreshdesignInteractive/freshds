General fresh-navbar
  • •Use exactly one fresh-navbar per page at the very top of the content area. Never nest navbars.
  • •Add hamburger only when a collapsible sidebar or mobile drawer is present on the same page. Wire the hamburger-click event to toggle that panel.
  • •Place the user avatar or account menu in the actions slot on the far right, always the last element in that slot.
  • •Limit the nav slot to top-level destination links only. Section or sub-page links belong in a sidebar or secondary nav, not in the navbar.
  • •Cap the nav slot at 5 destination items. Beyond 5, links overflow the bar at typical viewport widths. Move lower-priority destinations to a secondary menu or sidebar. Use fresh-topbar-menu with size="sm" as the nav slot content to get built-in hover and active states without custom styling.
Slots
SlotDescription
brandLogo or wordmark. Defaults to the FreshDS Acme SVG when omitted. Positioned left, before the nav slot.
navNavigation links. Positioned left, after the brand. Use a <nav> element with anchor tags inside.
actionsRight-side controls: search, notifications, avatar, CTA buttons.
Attributes
AttributeValuesDefaultDescription
hamburgerboolean-Adds a menu toggle icon button to the left of the brand slot. Fires hamburger-click on press.
Events

Accessibility

Navbar satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
landmarkThe bar renders as a <header> element, providing a navigation landmark automatically. Do not wrap it in another <header>.
hamburger labelThe hamburger button has a built-in aria-label="Open menu". Update this via ::part(hamburger) if the controlled panel has a more specific name.
icon buttonsAny icon-only button placed in the actions slot must have an aria-label describing the action (e.g. "Search", "Notifications").
