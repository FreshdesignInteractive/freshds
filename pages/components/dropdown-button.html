Dropdown Button

A button that opens a contextual menu of secondary actions. Also known as a menu button (W3C ARIA). Use when a primary label has multiple related variants or destinations. Options are passed as <option> children or a JSON items attribute.

Dropdown button states
Variants · Primary, secondary, ghost, and danger. Mirrors the fresh-button variant set.
Disabled disabled · The entire control is non-interactive. Pointer events are suppressed.
Sizes size="sm" size="md" size="lg" · Three height tiers: 28px small, 34px default, 40px large.
Rich items with descriptions items='[...]' · JSON items support optional desc for sub-labels, separator for dividers, and danger for destructive options.
All variants x all sizes · Full matrix: one row per size, all four variants across.

General fresh-dropdown-button
  • •Use a dropdown button when a single concept (Export, Actions) has 2 to 6 related variants. More than 6 options are better served by a modal or separate page.
  • •Always add class="danger" to destructive options (delete, remove, revoke). This renders them in red and signals caution before the user commits.
  • •Match the variant to the page context. Use primary for the page's main action, secondary for supporting actions, and ghost inside dense tool rows.
  • •Listen to the select event for menu picks. Use e.detail.value to dispatch the correct action, not the label text, which can change with localization.
  • •Use data-desc on option elements or the desc field in JSON items to add sub-labels. Reserve this for options that genuinely need disambiguation, not as a workaround for unclear labels.

Events
EventDetailDescription
select{ value, label }Fired when a menu item is chosen. detail.value is the option's value attribute. detail.label is its visible text.
Code
HTMLBasic dropdown
<fresh-dropdown-button
  label="Export"
  variant="primary"
>
  <option value="csv">Export as CSV</option>
  <option value="pdf">Export as PDF</option>
  <option value="png">Export as PNG</option>
</fresh-dropdown-button>
HTMLWith danger option and sm size
<fresh-dropdown-button
  label="Actions"
  variant="secondary"
  size="sm"
>
  <option value="edit">Edit</option>
  <option value="duplicate">Duplicate</option>
  <option value="delete" class="danger">Delete</option>
</fresh-dropdown-button>
JSHandle select event
document.querySelector('fresh-dropdown-button')
  .addEventListener('select', (e) => {
    if (e.detail.value === 'csv')      exportCSV();
    else if (e.detail.value === 'pdf') exportPDF();
    else if (e.detail.value === 'png') exportPNG();
  });

Accessibility
ConcernRequirement
Menu button patternThe trigger button has aria-haspopup="menu" and aria-expanded toggled between true and false as the menu opens and closes.
Menu itemsEach menu item renders with role="menuitem" and keyboard focus. Disabled items carry the native disabled attribute and are skipped by pointer events.
