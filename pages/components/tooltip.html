Tooltip

A wrapper component that shows a short text tip near any trigger element on hover or focus. Use to label icon-only controls or reveal supplemental context without cluttering the UI.

Tooltip placements
Top placement="top" · Default placement. Tip appears above the trigger. Best when there is space above.
Export Delete
Bottom placement="bottom" · Tip appears below the trigger. Use in toolbars near the top of the viewport.
Left placement="left" · Tip appears to the left of the trigger. Use for controls at the right edge of a panel.
Right placement="right" · Tip appears to the right of the trigger. Use for controls at the left edge of a panel.

General fresh-tooltip
  • •Always wrap fresh-tooltip around the trigger element as a parent, not a sibling. The component uses a slot to render the trigger and positions the tip relative to it.
  • •Use tooltips to label icon-only buttons. The tooltip text should match or closely describe the button's aria-label. Never use a tooltip as a substitute for the aria-label.
  • •Keep tooltip text short: one phrase or sentence maximum, under 60 characters. Tooltips are not help text. For longer explanations use a popover or inline description.
  • •Choose placement based on available viewport space, not aesthetics. Prefer top (default) for most cases. Use bottom for triggers near the top of the screen.
  • •Do not wrap interactive elements that already have visible text labels in a tooltip. Tooltips add value only when the label is absent or when supplemental context aids comprehension.

Accessibility

Tooltip satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
keyboard triggerThe tooltip shows on focusin and hides on focusout in addition to hover events, ensuring keyboard users see the same tip as mouse users.
roleThe tip bubble carries role="tooltip". The trigger element should reference it via aria-describedby if additional programmatic association is required beyond the shadow DOM boundary.
