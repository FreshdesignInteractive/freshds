Sidebar Menu

Vertical navigation panel composed from three parts: fresh-sidebar (shell with brand/footer slots), fresh-nav-group (collapsible labeled sections), and fresh-nav-item (individual links with icons and optional badges).

General fresh-sidebar
  • •Organise nav items into fresh-nav-group sections. A flat list of items with no grouping is only acceptable when there are five or fewer total destinations.
  • •Mark exactly one fresh-nav-item as active at any time, matching the user's current route.
  • •Use href on fresh-nav-item for real navigation links. Omit href and listen to the nav-click event for client-side routing or actions that don't change the URL.
  • •Reserve badge on a fresh-nav-item for short labels ("AI", "New", "Beta") or counts (unread notifications). Do not use long strings as badges.
  • •Toggle collapsed on the sidebar element to switch between icon-only and full label mode. Pair with a hamburger button in the navbar for touch/mobile contexts.

Accessibility

Sidebar Menu satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
nav landmarkWrap the fresh-sidebar in a <nav aria-label="Main navigation"> element so screen readers announce it as a navigation landmark.
collapsed stateWhen collapsed, nav item text is visually hidden but the icon remains. If items have no text slot content, ensure the icon has a meaningful aria-label or the item has tooltip support.
group toggleThe group header button uses cursor:pointer and is keyboard-focusable. The expand/collapse state is reflected visually by the chevron but should also be announced via aria-expanded where screen reader support is critical.
