Chart

A consistent container for any chart library, Chart.js, Recharts, D3, or custom SVG. Provides the FreshDS card header, border, and responsive padding. You supply the chart via the default slot.

Chart states
Area chart title + description · Card header is shown when either title or description is provided. Chart content goes in the default slot.
Bar chart default slot · Any SVG, canvas, or chart library output can go in the slot. Use --dv-1 through --dv-8 for series colors.
Multi-series --dv-1 through --dv-8 · Use dataviz tokens in series order starting at --dv-1. Do not use brand scale tokens for chart series.
Loading + empty loading · empty · Boolean attributes for loading shimmer and empty state. Use loading when data is fetching, empty when a query returns no results.
Header actions slot slot="actions" · Place buttons or controls in the actions slot. They render top-right in the card header alongside the title and description.

General fresh-chart
  • •Always use --dv-1 through --dv-8 tokens for chart series colors. Never use brand scale tokens (--primary-*, --secondary-*) inside charts.
  • •Assign series colors in order starting at --dv-1. Do not skip tokens or pick arbitrary ones. Consistent ordering makes multi-chart dashboards scannable.
  • •Show the loading state immediately when data is being fetched. Do not render a chart with empty or placeholder data, use loading then replace the attribute when data arrives.
  • •Always provide aria-hidden="true" on the chart SVG or canvas and describe the key insight in description so screen readers get context without parsing chart graphics.
  • •Load tokens/dataviz.css on any page that uses fresh-chart. The --dv-* tokens are defined in that file and are not included in theme.css.

Slots
SlotDescription
defaultYour chart element: an SVG, canvas, or a chart library component. Sized to fill the chart area via ::slotted(*) { width:100%; height:100%; }.
actionsButtons or controls rendered top-right in the card header. Requires title or description to be set for the header to appear.
Code
HTMLArea chart
<fresh-chart title="Monthly revenue" description="MRR across all plans, last 6 months" height="220px"> <svg viewBox="0 0 480 160" style="width:100%;height:100%" aria-hidden="true"> <!-- your chart path/rect elements here --> <!-- Use var(--dv-1) through var(--dv-8) for series colors --> </svg> </fresh-chart>
HTMLLoading then content
<!-- Loading skeleton while data fetches --> <fresh-chart title="Revenue" loading height="220px"></fresh-chart> <!-- Once data loads, replace loading with chart content --> <fresh-chart title="Revenue" height="220px"> <canvas id="revenue-chart"></canvas> </fresh-chart>
HTMLWith actions slot
<fresh-chart title="Sessions" description="Last 24 hours" height="200px"> <div slot="actions"> <fresh-button variant="ghost" size="sm"> <i class="ti ti-download"></i> Export </fresh-button> </div> <canvas id="sessions-chart"></canvas> </fresh-chart>

Accessibility

Chart wrapper satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
chart contentThe slotted chart SVG or canvas must carry aria-hidden="true". Use the description attribute or a visually-hidden text summary to communicate the key data insight to screen readers.
color-only seriesWhen rendering multi-series charts, do not rely on color alone to distinguish series. Add patterns, shapes, or labels directly in the chart so users with color vision deficiency can differentiate them.
loading stateThe shimmer overlay is aria-hidden="true". Announce loading status with a surrounding aria-live="polite" region if the chart is a primary content area.
