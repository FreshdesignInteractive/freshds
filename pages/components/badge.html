General fresh-badge
  • •Match variant to the semantic meaning: use success for healthy/complete states, danger for errors, warning for caution, never use color alone to convey meaning.
  • •Use dot only for real-time or live status, not for static category labels. The pulsing animation implies something is actively changing.
  • •Keep badge text concise: one or two words maximum. Badges are not sentences. Use a tooltip or inline label for longer explanations.
  • •Use size="sm" inside dense table rows or alongside small text. Use the default md size in cards, headings, and detail panels.
  • •Reserve variant="ai" exclusively for content that was AI-generated or for features that invoke an AI model. Do not use it as a novelty accent.

Accessibility

Badge satisfies all universal accessibility concerns. Component-specific concerns are below.

ConcernRequirement
color meaningNever rely on badge color alone to convey status. Always include a text label inside the badge so color-blind users receive the same information.
dot animationThe pulsing dot is decorative. It carries aria-hidden="true". The badge text must fully express the status without it.
