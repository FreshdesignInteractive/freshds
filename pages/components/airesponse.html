General fresh-ai-response
  • •Always set role="user" for user messages and role="assistant" for AI messages. Never use a single role for both sides of a conversation.
  • •Add the streaming attribute when appending tokens progressively. Remove it once the full response has been received so the cursor disappears.
  • •Set model to the actual model identifier returned by the API. Show it so users understand which model answered, especially in multi-model applications.
  • •Pair each assistant message with a fresh-feedback row immediately below it so users can rate every response without extra navigation.
  • •Do not truncate long responses. The component word-wraps automatically. If length is a concern, summarize server-side before rendering.
