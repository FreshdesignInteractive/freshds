Data Display

Stat card

Metric display combining a primary value, label, optional trend indicator, and icon. Use in dashboard grids to surface KPIs at a glance.

Default
No trend (informational only)
Attributes
AttributeValuesDefaultDescription
valuestring—The primary metric value to display
labelstring—Metric name below the value
trendnumber—Positive = up, negative = down, omit = no trend row
trend-labelstring—Context phrase e.g. "vs last month"
iconTabler class e.g. ti-users—Icon shown top-right
