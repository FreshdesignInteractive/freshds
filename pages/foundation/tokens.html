Generation rules Tier 1 · Tier 2 · Tier 3
  • •Always use Tier 2 semantic tokens (--surface-*, --text-*, --color-*) in all component code. Never reference Tier 1 raw scale steps (--primary-9, --scale-3) directly in a component; those are implementation details owned by theme.css.
  • •Never hardcode a hex, rgb, or hsl color value in a component. Every color must come from a CSS custom property. The only permitted raw values are inside tokens/primitives.css and js/freshds.js.
  • •Use --surface-canvas for card and panel backgrounds, --surface-subtle for hover tints and section backgrounds, --surface-overlay for dropdowns and tooltips. Never use --surface-bg inside a component; that is the page background only.
  • •For interactive brand-colored elements, use --color-interactive as the fill, --color-interactive-hover on hover, --color-interactive-subtle for selected row tints and ghost hover states, --color-interactive-text for colored text links and active nav labels.
  • •For status patterns (alert, badge, inline indicator), always apply the complete triplet for that status: --color-{status}-subtle as background, --color-{status}-border as border, --color-{status}-text as text. Never mix triplet tokens from different statuses.
  • •Use --color-ai (not --color-interactive) for all AI-initiated UI elements: sparkle icons, send buttons, AI response indicators, streaming cursors. AI tokens are a separate family: --color-ai, --color-ai-subtle, --color-ai-border, --color-ai-text, --btn-ai-hover.
  • •Box shadows for elevation use raw rgba(0,0,0,x) values only. Backdrop scrims (modal overlays) use rgba(0,0,0,0.4). These are the only cases where a raw color value is permitted outside of primitives files.
Code
/* Correct: semantic tokens */ .card { background: var(--surface-canvas); border: 1px solid var(--surface-border); color: var(--text-primary); } /* Wrong: raw scale step */ .card { background: var(--scale-1); } /* Wrong: hardcoded hex */ .card { background: #ffffff; }

The Light and Dark columns in the tables below show which raw scale step each token resolves to in each mode. Because the assignments flip, dark mode is automatic with no @media or class conditionals needed.
