Foundation

Tokens

Complete reference for every CSS custom property. Always use Tier 2 semantic tokens in your components — they resolve correctly in both light and dark mode without any extra work.

Usage
Reference tokens in CSS
/* ✓ Use semantic tokens */
.card {
  background: var(--surface-canvas);
  border: 1px solid var(--surface-border);
  color: var(--text-primary);
}

/* ✗ Never reference raw scale steps */
.card { background: var(--scale-1); }

/* ✗ Never hardcode hex */
.card { background: #ffffff; }

The Light and Dark columns show the scale step each token maps to. Since step assignments flip between modes, components automatically invert — no @media (prefers-color-scheme) or class conditionals needed.
