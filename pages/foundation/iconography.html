Iconography

FreshDS uses Tabler Icons, an open-source library of 5,000+ consistent 2px stroke icons. MIT licensed, free for commercial use. Loaded via icon font so no build step or SVG imports are required.

Usage
HTMLBasic icon
<i class="ti ti-sparkles"></i>

Replace sparkles with any name from tabler.io/icons. The class pattern is always ti ti-{name}.

Usage ti ti-{name}
  • •Always pair an icon with a visible text label for actions. A standalone icon is only acceptable for universally understood symbols (close, search) and only when space is critically constrained. Always include aria-label on the parent button when the label is hidden.
  • •Size icons to match the surrounding text context: 14px alongside 12-13px body copy, 16px as the default inline size, 20px for medium-emphasis UI elements, 24px for primary navigation items, 32px for empty states and hero callouts.
  • •Use icons from the Tabler library only. Never inline custom SVGs or reference other icon libraries. The class pattern is always ti ti-{name}. Browse available icons at tabler.io/icons.
  • •Color icons with DS text or semantic tokens, never hardcoded hex. Use --text-secondary for decorative icons, --text-primary for active/selected icons, --color-danger for destructive action icons.
  • •Use AI-specific icons (ti-sparkles, ti-brain, ti-wand, ti-circuit-ai) exclusively for AI-initiated actions or AI UI components. Do not use them for general actions to avoid misleading users about feature origin.
Accessibility

Icons are decorative by default. Accessibility is the responsibility of the element that contains them.

ConcernRequirement
decorative icons Add aria-hidden="true" to the <i> element when an adjacent text label already describes the action. This prevents screen readers from announcing the icon glyph name.
icon-only buttons When no visible label is present, the parent <button> must carry aria-label="Action name". The icon gets aria-hidden="true". Example: <button aria-label="Close"><i class="ti ti-x" aria-hidden="true"></i></button>
color contrast Icons used to convey information (status, error, success) must not rely on color alone. Pair with a text label or use a shape distinction alongside the color.
