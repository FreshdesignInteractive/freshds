Accessibility

FreshDS targets WCAG 2.2 AA conformance across all components. This page defines the universal concern checklist every interactive component satisfies, plus component-specific additions and AI generation rules.

Conformance target
WCAG 2.2 Level AA
All FreshDS components are built and tested against WCAG 2.2 AA. AAA criteria are implemented where they do not conflict with usability, notably focus appearance (2.4.11) and target size (2.5.5). Components are tested with VoiceOver (macOS/iOS), NVDA (Windows), and the axe browser extension.

Generation rules WCAG 2.2 AA
  • •Every interactive element must have an accessible name. Icon-only <button> gets aria-label="Action name". <input> gets an associated <label for="id"> or aria-label. Never emit a bare interactive element without one.
  • •Decorative icons (those with an adjacent text label) always get aria-hidden="true". If an icon is the sole content of a button or link, the parent element carries aria-label describing the action, not the icon glyph name.
  • •Never use color as the sole signal for state (error, success, warning, disabled, selected). Always combine color with one of: a text label, a Tabler icon, or an ARIA attribute (aria-invalid, aria-selected, aria-disabled).
  • •Prefer semantic HTML over ARIA roles: use <button> not <div role="button">, <nav> not <div role="navigation">, <main> not <div role="main">. Add explicit ARIA roles only when no native HTML element is semantically appropriate.
  • •Error states on form controls require all three: aria-invalid="true" on the input, an error message element visible in the DOM, and aria-describedby="error-id" on the input pointing to that message. Never show an error only visually.
  • •Dynamic content updates use live regions: aria-live="polite" for non-urgent additions (search results, suggestions), role="alert" (implicit assertive) for errors and critical notices only. Never use assertive for routine updates.
  • •Overlay components (modal, drawer, popover) require the full triad: focus trap cycling Tab/Shift+Tab within the overlay while open; Escape key closes; focus returns to the exact trigger element on close. Implement all three or none.
  • •Never set tabindex to a positive integer. Use tabindex="0" to add a non-interactive element to tab order, tabindex="-1" to enable programmatic focus only. Positive tabindex values break the natural reading order.
Universal concerns

Every interactive component in FreshDS satisfies all of the following. Component pages only document concerns beyond this base set.

Concern WCAG Requirement
role 4.1.2 AA Use semantic HTML where possible. <button>, <input>, <a> carry implicit roles. Add explicit ARIA roles only when no native element is available.
accessible name 4.1.2 AA Every interactive element must have a programmatic name. Derives from visible text, aria-label, aria-labelledby, or an associated <label>. For icon-only controls, always provide aria-label.
keyboard 2.1.1 AA Every function must be operable via keyboard alone. Native HTML elements handle Enter/Space activation automatically. Custom components must replicate expected key behaviour for their ARIA role.
focus ring 2.4.11 AA Visible focus indicator required on :focus-visible. FreshDS uses a 2px white gap and 4px outer ring using the primary scale. Never suppress outline without an equivalent custom indicator.
colour contrast 1.4.3 AA Text on component surfaces must meet 4.5:1 minimum. Large text (18px+ or 14px bold) and UI component boundaries require 3:1. Verify after every theme change, especially primary and danger variants where background shifts with the customer palette.
icon decoration 1.1.1 AA Icons alongside text are decorative. Mark them aria-hidden="true" so screen readers do not announce CSS class names. Standalone icons require aria-label or visually-hidden companion text.
disabled state 4.1.2 AA Set both the native disabled attribute and aria-disabled="true". Screen readers announce the element as "dimmed" or "unavailable". Opacity drops to 38% to communicate inactivity visually.
touch target 2.5.8 AA Minimum touch target is 24x24 CSS pixels (WCAG 2.2 AA). FreshDS targets 44x44px (WCAG 2.1 AAA / 2.5.5). size="lg" reaches 40px height. Ensure adequate tap padding on mobile viewports for smaller sizes.
Component-specific additions

These concerns apply to specific component types beyond the universal base set above. Each component page documents its own entries from this list.

Component type Additional concerns
Button loading state sets aria-busy="true" during async operations. Pair with an updated aria-label like "Saving..." to give spoken context beyond the spinner visual.
Input / Form field required sets aria-required="true" alongside the visible indicator. error state sets aria-invalid="true" and links the error message via aria-describedby. Set autocomplete tokens for personal data fields.
Checkbox / Radio checked state exposes aria-checked in sync with visual state. group labeling wraps related controls in <fieldset> with <legend> so screen readers announce the group name before each option.
Modal / Drawer focus trap cycles tab focus within the overlay while open. Escape key always closes. return focus goes back to the triggering element on close. Uses role="dialog" + aria-modal="true" + aria-labelledby pointing to the heading.
Dropdown / Popover expanded state trigger carries aria-expanded. Escape key closes and returns focus to trigger. Arrow key navigation Up/Down moves between items; Home/End jumps to first/last.
Tabs selected state active tab has aria-selected="true", others aria-selected="false". Arrow key navigation Left/Right moves between tabs. Panels linked via aria-controls and aria-labelledby.
Accordion expanded state trigger button carries aria-expanded. Panel linked to trigger via aria-controls. The trigger must be a <button>, not a div or heading alone.
Toast / Alert Informational toasts use aria-live="polite". Critical alerts use role="alert" (implicit live="assertive"). Auto-dismiss minimum 5 seconds. Never dismiss while the user is focused inside the toast.
Data table <th scope="col"> required on column headers. Sortable headers carry aria-sort (ascending / descending / none). Selected rows carry aria-selected="true".
