Foundation

Accessibility

FreshDS targets WCAG 2.2 AA conformance across all components. This page defines the universal concern checklist every interactive component satisfies, plus the additions specific to each component type.

Conformance target
WCAG 2.2 Level AA
All FreshDS components are built and tested against WCAG 2.2 AA. AAA criteria are implemented where they don't conflict with usability, notably focus appearance (2.4.11) and target size (2.5.5). Components are tested with VoiceOver (macOS/iOS), NVDA (Windows), and the axe browser extension.
Universal concerns

Every interactive component in FreshDS satisfies all of the following. Component pages only document concerns beyond this base set.

Concern WCAG Requirement
role 4.1.2 AA Use semantic HTML where possible, <button>, <input>, <a> carry implicit roles. Add explicit ARIA roles only when a native element is not available.
accessible name 4.1.2 AA Every interactive element must have a programmatic name. Derives from visible text content, aria-label, aria-labelledby, or an associated <label>. For icon-only controls, always provide aria-label.
keyboard 2.1.1 AA Every function must be operable via keyboard alone. Native HTML elements handle Enter/Space activation automatically. Custom components must replicate expected key behaviour for their role.
focus ring 2.4.11 AA Visible focus indicator required on :focus-visible. FreshDS uses a double-ring: 2px white gap + 4px outer ring using the primary scale. Never suppress outline without an equivalent custom indicator.
colour contrast 1.4.3 AA Text on component surfaces must meet 4.5:1 minimum. Large text (18px+ or 14px bold) and UI component boundaries require 3:1. Verify after every theme change, especially primary and danger variants where background shifts with the customer palette.
icon decoration 1.1.1 AA Icons alongside text are decorative, mark them aria-hidden="true" so screen readers don't announce CSS class names. Standalone icons require aria-label or visually-hidden companion text.
disabled state 4.1.2 AA Set both the native disabled attribute and aria-disabled="true". Screen readers announce the element as "dimmed" or "unavailable". Opacity drops to 38% to communicate inactivity visually.
touch target 2.5.8 AA Minimum touch target is 24×24 CSS pixels (WCAG 2.2 AA). FreshDS targets 44×44px (WCAG 2.1 AAA / 2.5.5), size="lg" reaches 40px height. Ensure adequate tap padding on mobile viewports for smaller sizes.
Component-specific additions

These concerns apply to specific component types beyond the universal base set above. Each component page documents its own entries from this list.

Component type Additional concerns
Button loading state, sets aria-busy="true" during async operations. Pair with an updated aria-label like "Saving…" to give spoken context beyond the spinner visual.
Input / Form field required, set aria-required="true" alongside the visible indicator. error state, set aria-invalid="true" and link the error message via aria-describedby. autocomplete, set the appropriate token value for personal data fields.
Checkbox / Radio checked state, expose aria-checked in sync with visual state. group labeling, wrap related controls in <fieldset> with a <legend> so screen readers announce the group name before each option.
Modal / Drawer focus trap, tab focus must cycle within the overlay while open. escape key, pressing Escape always closes. return focus, on close, focus returns to the element that triggered the overlay. role="dialog" + aria-modal="true" + aria-labelledby pointing to the heading.
Dropdown / Popover expanded state, trigger element carries aria-expanded. escape key, closes and returns focus to trigger. arrow key navigation, Up/Down moves between items; Home/End jump to first/last.
Tabs selected state, active tab has aria-selected="true"; others have aria-selected="false". arrow key navigation, Left/Right moves between tabs. Tab panels are linked via aria-controls / aria-labelledby.
Accordion expanded state, trigger button carries aria-expanded. Panel is linked to its trigger via aria-controls. Trigger must be a <button>, not a div.
Toast / Alert live region, informational toasts use aria-live="polite"; critical alerts use role="alert" (implicit live="assertive"). auto-dismiss timing, minimum 5 seconds before auto-removal; never dismiss while the user is focused inside the toast.
Data table column headers, <th scope="col"> required. sort state, sortable headers carry aria-sort (ascending / descending / none). row selection, selected rows carry aria-selected="true".
